# ピタッとビート

おとに あわせて ピタッ！ ブラウザで遊べる4レーンのリズムゲーム。小学生向け・タブレット（Fire タブレットの Silk ブラウザ）とパソコンで動く。

- 本体は `index.html` 1枚。曲はゲームの中で鳴らす自作の電子音（音声ファイルなし・著作権の心配なし）
- 操作: 画面のレーンをタッチ／キーボード `D F J K` か `← ↓ ↑ →`。Esc でひとやすみ
- 記録はその端末の中だけ（localStorage）。外には送らない

## 調整する場所（index.html の中）

| やりたいこと | 場所 |
|---|---|
| 判定の幅を変える | `[設定]` の `JUDGE`（秒。いま ピタッ±0.04 / ナイス±0.08 / おしい±0.12） |
| レベルが開く★の数 | `[設定]` の `LEVELS` の `need` |
| 1日10分の制限をつける | `[1日の時間]` の `PlayLimit.enabled` を `true`（`dailySec` が秒数） |
| 曲を足す | `[曲]` の `SONGS` に1つ足す（BPM・キー・コード進行・構成・seed） |
| 譜面の密度 | `[譜面]` の `buildChart` |
